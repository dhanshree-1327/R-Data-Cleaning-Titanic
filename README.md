# R-Data-Cleaning-Titanic
# R Data Cleaning and Preliminary Analysis

## Week 1 Internship Task

This project performs data cleaning, preprocessing, and preliminary
exploratory analysis of the Titanic passenger dataset using R.

## Tasks Performed

- Dataset inspection
- Missing value analysis
- Missing value treatment
- Outlier detection using IQR
- Categorical variable encoding
- Numerical variable standardization
- Descriptive statistics
- Correlation analysis
- Data visualization

## Technologies

- R
- RStudio
- tidyverse
- ggplot2

## Dataset

Titanic – Machine Learning from Disaster
Source: Kaggle

## Files

- `titanic_week1_analysis.R` – R analysis code
- `titanic_cleaned_week1.csv` – cleaned dataset
- `titanic_missing_value_report.csv` – missing-value report
- `README.md` – project documentation
